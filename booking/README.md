# 별빛민박 예약 시스템

숙박업 신고를 마친 업소 1곳을 위한 예약·결제 웹사이트입니다.
객실 조회 → 날짜별 예약 가능 여부 확인 → 예약자 정보 입력 → 카드 결제(토스페이먼츠) → 예약 확정까지 한 번에 처리됩니다.

이 폴더는 상위 폴더(별빛민박 홈페이지)와 함께 하나의 서버로 실행됩니다.
`npm start`로 실행하면 `http://localhost:3000` 에서 홈페이지가, `http://localhost:3000/booking` 에서 예약 시스템이 동시에 열립니다.
홈페이지의 "온라인 예약" 버튼(네비게이션 바, 히어로, 예약 문의 섹션)이 `/booking`으로 연결되어 있습니다.

## 1. 준비물

- 사업자등록증 (숙박업 신고를 마친 사업자)
- **영업신고증(숙박업 신고증)** — 토스페이먼츠 등 PG사 가맹점 심사 시 요구됩니다.
- Node.js 18 이상이 설치된 서버 또는 호스팅 환경 (예: 카페24, 가비아, AWS Lightsail, Railway 등)

## 2. 설치

```bash
npm install
cp .env.example .env
```

`.env` 파일을 열어 아래 항목을 실제 값으로 채워주세요.

- `BUSINESS_NAME`, `BUSINESS_PHONE`, `BUSINESS_ADDRESS` : 사이트에 표시될 업소 정보
- `BUSINESS_LICENSE_NO` : 영업신고증 상의 신고번호 (하단에 표시되어 고객 신뢰도를 높입니다)
- `TOSS_CLIENT_KEY`, `TOSS_SECRET_KEY` : 아래 3번 항목 참고

## 3. 결제(토스페이먼츠) 연동 방법

1. https://developers.tosspayments.com 에서 회원가입 후 **상점 등록** 신청
   - 이때 사업자등록증과 **숙박업 영업신고증**을 함께 제출하게 됩니다. (숙박업은 PG사에서 별도 심사하는 업종입니다)
2. 심사 승인 전에는 대시보드에서 제공하는 **테스트 키**(`test_ck_...`, `test_sk_...`)로 먼저 결제 흐름 전체를 검증해보세요. 테스트 키는 실제 카드 승인 없이 결제 성공/실패 흐름만 확인할 수 있습니다.
3. 심사가 완료되면 **라이브 키**(`live_ck_...`, `live_sk_...`)로 `.env` 값을 교체하면 실제 결제가 시작됩니다.

## 4. 객실 등록

`seed.js` 파일에서 객실명, 설명, 인원, 1박 가격을 실제 값으로 수정한 뒤 아래 명령을 실행하세요.

```bash
npm run seed
```

객실 사진은 `public/img/` 폴더에 넣고, `seed.js`의 `image_url` 경로를 맞춰주면 됩니다.

## 5. 실행

이 폴더(`booking/`) 안에서 실행합니다.

```bash
npm install
npm start
```

`http://localhost:3000` 이 별빛민박 홈페이지, `http://localhost:3000/booking` 이 예약 시스템입니다.
실제 도메인에 연결하려면 호스팅 업체의 Node.js 배포 가이드를 따라 프로젝트 폴더(홈페이지 파일 + `booking/` 폴더) 전체를 그대로 올리고, 이 `booking` 폴더에서 `npm start`를 실행하면 됩니다.

※ 정적 파일만 지원하는 호스팅(예: 깃허브 페이지)에는 올릴 수 없습니다. Node.js 실행이 가능한 호스팅(카페24, 가비아 Node 호스팅, Railway, AWS Lightsail 등)이 필요합니다.

## 6. 동작 방식 (참고)

- 예약은 결제 전 `PENDING` 상태로 먼저 저장되어, 같은 방을 두 사람이 동시에 예약하는 것을 막습니다. 10분 안에 결제가 완료되지 않으면 자동으로 취소됩니다.
- 결제 승인은 **서버에서** 토스페이먼츠 API로 한 번 더 검증합니다(금액 위변조 방지). 프론트엔드에서 온 금액만 믿고 승인하지 않습니다.
- 데이터는 `booking.db`(SQLite) 파일 하나에 저장됩니다. 별도 DB 서버 설치 없이 바로 운영할 수 있고, 예약이 많아지면 추후 MySQL/PostgreSQL로 옮길 수 있습니다.

## 7. 자주 필요한 추가 기능 (원하시면 이어서 작업 가능)

- 관리자 페이지(예약 현황 확인, 수동 취소)
- 예약 확정 문자/카카오 알림톡 발송
- 계좌이체(무통장입금) 결제 방식 추가
- 다중 업소/객실 확장
